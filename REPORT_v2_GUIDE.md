## 🔍 Filter Examples

### Grouped Issues Filter
```
Search: "error"
Result: Shows only rows with "error" in level/source/message

Search: "SQL"
Result: Shows only SQL Server entries

Search: "deadlock"
Result: Shows only deadlock-related entries

Search: ""
Result: Shows all rows (filter cleared)
```

### Timeline Filter
```
Search: "APP-01"
Result: Shows only APP-01 server events

Search: "Error"
Result: Shows only Error-level entries

Search: "timeout"
Result: Shows only entries with "timeout" in message

Search: "14:32"
Result: Shows entries around 14:32
```
